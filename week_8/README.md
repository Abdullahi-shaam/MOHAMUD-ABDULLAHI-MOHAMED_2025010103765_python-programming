# Food Delivery System

## Purpose

This program allows a user to place a food order and automatically prints a receipt with:

- Customer information
- Food ordered
- Quantity
- Price
- Subtotal
- 5% service charge
- Delivery charge
- Grand total

## Tech Stack

- Python 3

## How to Use

1. Run main.py
2. Enter customer name.
3. Enter food ordered.
4. Enter quantity.
5. Enter price per item.
6. Choose delivery (Y/N).
7. The receipt will be displayed.
